A tutorial in 9 short lessons

Building Featherbase test-first

How a real project begins: one sentence, one failing test, the least code that passes.

Before you startWhat you need

A computer with Bun and git installed, and a copy of the Featherbase repository on the branch first-build-welcome-page.

The lessonsEach one follows one small step in the history

  • Lesson 1The first failing testWe write no page at all. We write the proof that the page is missing, and save that failure on purpose.
  • Lesson 2The least code that passesThe test is failing because nothing starts. In this lesson we write the smallest program that makes it pass, and we resist writing anything more.
  • Lesson 3A second behaviour: page not foundWe found a flaw: every address shows the welcome page. Before fixing it, we write down what should happen instead, and a test that fails until it does.
  • Lesson 4The least fix for page not foundThe program learns to look at the address, and we look closely at what an address is made of.
  • Lesson 5Changing the tool without changing the behaviourWe hand-wrote address matching. Frameworks exist to do that. This lesson swaps the tool underneath while the tests stand guard, and that is what the word refactor means.
  • Lesson 6Letting the tests see the codeWe want to know which lines no test proves. The tool for that is called coverage, and the first time we switch it on it shows us nothing at all. This lesson finds out why and fixes it.
  • Lesson 7A gate that says noMeasuring is not enforcing. This lesson makes the test run fail whenever any line is unproven, and shows how to prove that a setting works when there is nothing to write a test about.
  • Lesson 8Proving the front doorTwo lines of our project are checked by nothing: the file that starts Featherbase. This lesson tests it, and deals honestly with a test that passes the first time it is run.
  • Lesson 9A machine that never forgetsEvery check so far runs only when a person runs it. This last lesson hands the job to GitHub, so that every push is tested on a clean machine without anyone remembering.
