# Foundations

What every feature relies on. Each foundation has its own folder, its own name and its own sentences.

A thing with no behaviour worth a sentence is not a foundation; it is code inside something else.

| Foundation | What it is |
|---|---|
| `home` | The first page: what there is, and where to start |
| `pages` | The page frame, the styles, and the mock-up every screen is cut from |
| `ui-preferences` | How a record opens, and the row height |
| `refusing` | How a refusal is worded |
| `api` | How every call is shaped |
| `mcp` | The door for agents |
| `database` | How Tables, rows and Featherbase's own records are stored |
