# Confirming

The scene: a person is looking at the Table Featherbase would make and decides to create it.

## Acceptance criteria

Proposed by Claude while building the journey `journeys/importing-a-spreadsheet.md`. Not yet agreed by Siraj.

1. Pressing Create Table makes the Table with every row and opens its list.
2. The Table keeps the name it was shown with, whatever spaces and marks the file's name has.
3. The Table is made with the name the person typed.
4. The Table is made with the type the person chose for each Column.
5. The Table is made with the key the person chose.
6. A name that a Table already has is refused: the proposal comes back saying so, and nothing is made.
7. The list that opens says what was made: "Created Stores with 2 rows".
