# Report

## Purpose

A Report page turns a parameterized query into an inspectable business result.
It owns parameters, tabular output, totals, chart projection, saved variants,
export and navigation back to underlying records.

## Current scope

Summary, query and script reports exist in the generic Admin. Application-owned
declaration and consistent drill-through remain incomplete.
