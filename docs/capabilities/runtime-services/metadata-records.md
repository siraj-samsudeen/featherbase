# Metadata and records

## Purpose

Metadata defines records once and drives storage, APIs, validation, permissions
and generic user interfaces from the same declaration.

## Current scope

Installed runtime applications can own tables and use the governed row
lifecycle. This is the foundation on which the rest of the portable application
model builds.
