# Queries and saved views

## Purpose

This service gives standard pages and custom code one permission-aware way to
find, order, page and preserve useful record sets.

## Current scope

The query and saved-view behavior is available. Declarative pages still need a
portable contract that consumes it without application-specific wiring.
