# Audit, comments and engagement

## Purpose

Security audit answers who changed what. Comments support collaboration.
Application engagement is a separate opt-in measure of how a user actively used
a surface; it must not be confused with the security log.

## Current scope

Audit history and comments exist. Training needs visible-tab active time,
measured by heartbeat while the lesson is visible. That engagement contract and
the unified application timeline are not yet specified.
