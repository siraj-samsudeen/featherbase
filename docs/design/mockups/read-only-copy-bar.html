Option A (recommended): the editable copy's bar, with two buttons

Same card and place as today's "Copied from … · Copy again" bar. One line says what the copy holds; both actions are always in view. Below it, one notice for a load waiting or the last load's refusal. Pros: nothing new to learn, both actions one click, the reason a load failed is in plain sight. Cons: two buttons side by side; "Load now" could be pressed when "Check" was meant (it only reloads the same run, so no harm).
