# Record Workspace

## REMOVED Requirements

### Requirement: Navigate related rows through one contextual workspace

**Reason**: The row page's connection chips and the drill pane replace the Related area, so there
is one way to reach related rows from a list or a row.
**Migration**: relational-navigation's "A row page shows its connections under its name", "Two
links from the same table stay separate groups" and "A new row from a group starts linked to the
row". Searching a group's rows moves to the full list it opens as.
