## Why

On 18-Nov-2026 the owner saw the "We couldn't sign you in" card after a failed Microsoft sign-in offer a different set of ways in, in a different order and style, from the first sign-in page: StyleHR as a blue main button, "Try another Microsoft account", and an "Other ways to sign in" link (#1283).

## What Changes

- The "We couldn't sign you in" card is exactly the first page with its message above it (the UI owner's option C, 18-Nov-2026): the same form (StyleHR's, where it is connected), "or", and one shared panel of the other ways in. Same ways in, same order (Google, Microsoft, each connected service, then user name and password), same button; none is promoted.
- User name and password is a button, "Sign in with user name and password", everywhere. The "Other ways to sign in" link is gone.
- The way in that just failed keeps its place, as "Try another Google account" or "Try another Microsoft account".
- The card adds only its heading and one sentence. The panel leaves out only the way in whose form is open above it.
