# Comfortable everyday task management

## Why

Managing work should be efficient with a keyboard and understandable during loading, errors and conflicts. The interface must remain usable on small screens and with enlarged content.

## What Changes

- Add consistent Enter/Escape behavior and predictable focus.
- Present current progress, errors and conflicting values without stale feedback.
- Provide accessible controls and responsive layouts for all existing flows.

## Capabilities

### New Capabilities
- `task-usability`: Keyboard, feedback, accessibility and layout behavior.

### Modified Capabilities
None; this adds interaction requirements without changing saved business data.

## Impact

Depends on `03-projects-and-reliable-editing`. Applies to the existing Todo and Project interfaces, including recovery and conflict review.
