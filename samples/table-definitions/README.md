# Sample Table definitions

Made-up Tables for the draft in `TABLE-DEFINITIONS.md` at the top of the repository. No real person,
place or figure appears here. Nothing reads these files yet.

- `employees.json`: what the import would propose for `samples/employees/employees.csv`.
- `region.json`, `cluster.json`, `site.json`, `floor.json`, `department.json`, `section.json`: a small
  retailer's places, to show what a row belongs to.
- `person.json`, `job_assignment.json`: a Table whose rows are dated, and a way that goes through it.
- `ticket.json`: a package's Table that belongs to a place and to a person.
- `table-definition.schema.json`: a draft checker for the format.
